# 消防找茬 - 规则与说明

本游戏为**大家来找茬**玩法，结合消防/安全场景。本文档为该游戏在 `src/games/fire-equipment-rally/` 下的唯一说明文档，涵盖玩法、死亡/超时规则、实现要点、技术要求与可选扩展。

---

## 游戏定位与目标

- **玩法**：左右两幅图几乎相同，存在若干处差异，玩家点击正确区域即可标记，全部找完即过关。
- **目标**：在每一关中找出左右两图的全部差异（每关通常 5～7 处）；多关连续进行，全部通过后进入结束页，展示总关数、总找茬数等统计。

---

## 屏幕与流程

| 屏幕     | 说明 |
|----------|------|
| **开始页** | 标题、玩法说明、按钮「开始游戏」。点击后进入找茬页第 1 关。 |
| **找茬页** | 左图与右图并排（移动端可上下排列），顶部显示第几关、进度「已找 x / 总数」、剩余误点、剩余时间。点击左/右图命中差异则高亮；全部找完则本关通过。 |
| **本关通过** | 弹层「本关通过」，按钮「下一关」或「查看结果」。有下一关则进入下一关，否则进入结束页。 |
| **结束页** | 总关卡数、通过关数、总找茬数；按钮「再玩一次」。 |

---

## 单关规则细节

### 差异与点击判定

- 每关差异数量由关卡数据决定，建议 5～7 处；界面显示「已找 x / 总数」。
- 点击左图或右图：系统将点击转为相对坐标 (cx, cy)，检查是否落在某**未找到**的差异判定圆内（圆心与半径均为 0～1 相对比例）。
- **命中**：该处记为已找到并高亮（描边闭合动画）；**未命中**：记为一次错误点击，Toast「再试试」。
- 同一差异在左/右图各有判定区域；任一侧命中一次即算找到。已找到区域不再参与判定，重复点击不扣误点。

### 死亡规则（误点次数上限）

- 每关有**最大错误点击次数**（常量 `MAX_WRONG_CLICKS_PER_LEVEL`，如 5 次）。
- 达到上限且本关未找齐时，弹出「本关失败」，提供「重试本关」或「返回开始」。
- 重试本关时误点次数与倒计时均重置。

### 超时规则（单关限时）

- 每关有**限时**（常量 `LEVEL_DURATION_SEC`，如 60 秒）；时间到未找齐即**本关超时**。
- 找茬页顶部展示剩余时间（如 00:45）；剩余 ≤ `TIMEOUT_WARNING_SEC`（如 10 秒）时数字变红并有「即将超时」Toast 提醒一次。
- 超时后弹出「本关超时」，同样提供「重试本关」或「返回开始」；重试时倒计时重新给满。
- 若同时超时且误点达上限，**优先按超时**处理。

### 小知识与提示

- **小知识**：每找到一处差异，页面下方展示该差异对应的小知识（若在关卡数据中配置 `tip`）；仅展示最近一次找到的差异的 tip；**仅作文本展示，不解析 HTML**，避免 XSS。
- **提示**（可选）：每关可提供有限次「提示」，短暂高亮一处未找到的差异，不自动记为找到、不扣误点。

---

## 胜负与统计

- **本关胜利**：当前关所有差异均被找到。
- **本关失败（死亡）**：误点次数达到上限且未找齐；可重试本关或返回开始。
- **本关超时**：限时内未找齐；可重试本关或返回开始。
- **结束页统计**：总关卡数、通过关数、总找茬数。

## 技术说明与实现要点

- **路由**：`/game/fire-equipment-rally`
- **目录**：`src/games/fire-equipment-rally/`
- **样式**：类名前缀 `fer-`，遵循工程《UI 规范》。

### 常量（`constants.ts`）

| 常量 | 说明 |
|------|------|
| `MAX_WRONG_CLICKS_PER_LEVEL` | 每关最大误点次数，0 表示不限制。 |
| `LEVEL_DURATION_SEC` | 每关限时（秒），0 表示不限时。 |
| `TIMEOUT_WARNING_SEC` | 剩余多少秒时做超时提醒。 |

### 状态（`gameStore`）

- 死亡：`wrongClicks`、`isLevelFailed()`；超时：`levelTimeRemaining`、`isLevelTimedOut`；`tick()` 每秒由 Game 的 setInterval 调用。
- `start` / `nextLevel` / `retryLevel` 时重置误点与倒计时。

### 类型（`types.ts`）

- `CircleRegion`：单侧图上圆形判定区域 (cx, cy, r)，0～1 相对比例。
- `DifferenceRegion`：id、left、right（CircleRegion）、tip（可选）。
- `SpotDifferenceLevel`：id、title、leftImage、rightImage、differences（readonly）。
- `SPOT_LEVELS`：readonly 关卡列表。

---

## 技术要求（与代码一致）

1. **React Hooks**：所有 Hooks（useRef、useCallback、useEffect）必须在任何条件 return 之前调用，保证每次渲染调用顺序一致，符合 Rules of Hooks。
2. **超时计时器**：useEffect 依赖仅 `[gameStore.screen, gameStore.currentLevelIndex]`；过关或失败时在 interval 回调内检测并 clearInterval，避免重复 tick。
3. **安全**：小知识 `tip` 仅作为 React 文本子节点渲染，不使用 `dangerouslySetInnerHTML`。
4. **性能**：点击判定使用平方比较避免开方；handleImageClick 使用 useCallback 且依赖稳定。

---

## 可选扩展

- **按关配置**：每关独立配置最大误点、限时（如简单关 90 秒/6 次误点，困难关 60 秒/4 次）。
- **生命值**：引入生命数，本关失败扣 1 命，命数为 0 时结束游戏并区分「通关结束」与「失败结束」。
- **提示功能**：每关 1～2 次提示，高亮一处未找到的差异。

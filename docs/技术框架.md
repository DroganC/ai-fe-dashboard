# 技术框架（通用）

适用于采用本技术栈的前端工程，不依赖具体业务模块。

---

## 一、技术栈

| 类别     | 技术               | 说明 |
| -------- | ------------------ | ---- |
| 语言     | TypeScript         | 建议 ^5.x，开启严格模式 |
| 框架     | React              | 建议 ^18.x |
| 构建工具 | Vite               | ESM，建议 ^5.x |
| 路由     | react-router-dom   | 建议 ^6.x |
| 状态管理 | MobX + mobx-react-lite | 全局/模块级状态 |
| UI 组件  | antd-mobile        | 移动端 H5，按需使用 |
| 样式     | Less               | 变量、嵌套、主题 |
| 运行环境 | 现代浏览器         | ES2020+，支持 ES Module |

- **模块规范**：`package.json` 中 `"type": "module"`，全工程 ESM。
- **TypeScript**：建议 `strict: true`，路径别名如 `"@/*": ["src/*"]`，`jsx: "react-jsx"`。

---

## 二、工程骨架（推荐）

```
├── index.html
├── package.json
├── tsconfig.json
├── tsconfig.node.json
├── vite.config.ts
├── docs/                 # 项目级文档
└── src/
    ├── main.tsx          # 入口：createRoot + Router + App
    ├── App.tsx           # 根组件、Routes 配置
    ├── index.less        # 全局样式入口
    ├── theme/            # 主题变量（见 UI 规范）
    │   └── colors.less
    └── vite-env.d.ts
```

- 入口链：`index.html` → `src/main.tsx` → 挂载根组件，路由在根组件或 `App.tsx` 中配置。

---

## 三、开发与构建

| 命令            | 说明 |
| --------------- | ---- |
| `npm run dev`   | 启动 Vite 开发服务器 |
| `npm run build` | 建议：先 `tsc -b` 再 `vite build`，产出到 `dist/` |
| `npm run preview` | 预览构建产物 |

- 构建前做 TypeScript 检查，路径别名在开发与构建中一致生效。

---

## 四、代码约定（通用）

- **TypeScript**：公开 API 与复杂状态补充类型与必要注释。
- **状态**：全局/模块级用 MobX，组件内用 React state/ref；定时器、订阅等在组件卸载时清理。
- **样式**：优先使用主题变量（见《UI 规范》），模块样式引用 `theme/colors.less`。
- **文档**：通用框架说明放 `docs/`，业务/功能说明放对应模块下的 `docs/` 或根目录 `docs/`。

以上为通用技术框架说明，具体项目可在 `docs/` 内增加「项目说明」引用本文并补充路由、目录等。

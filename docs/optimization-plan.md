# 灭火器连连看 & 工程优化计划

## 一、体验与交互（UX）

| 序号 | 项 | 说明 | 优先级 |
|------|----|------|--------|
| 1.1 | 消除反馈 | 消除时格子增加「缩小/淡出」动画，再清空，避免突兀消失 | P1 |
| 1.2 | 误触防抖 | 消除动画与连线播放期间禁用点击，避免连续误触 | P1 |
| 1.3 | 无解检测 | 重排前检测当前局面是否无解；无解时自动重排或明确提示 | P2 |
| 1.4 | 提示次数 | 可选：限制提示次数或冷却时间，增加轻度策略性 | P3 |
| 1.5 | 音效/震动 | 消除成功、提示、无解时短音效或 H5 震动（可选） | P3 |

---

## 二、视觉与主题（UI）

| 序号 | 项 | 说明 | 优先级 |
|------|----|------|--------|
| 2.1 | 格子过渡 | 格子状态变化（选中、hint、empty）增加 transition，统一时长与缓动 | P1 |
| 2.2 | 连线样式 | 连线可选用主题变量 `--fe-line-stroke-subtle` 做半透明柔和线 | P2 |
| 2.3 | 开始/结束页 | 开始页、结束页与游戏页统一 Fintech 色系与圆角、阴影规范 | P2 |
| 2.4 | Toast 样式 | 知识 Toast 与 antd-mobile 主题统一（圆角、背景、字色） | P2 |
| 2.5 | 深色模式 | 主题变量支持暗色切换（可选，与 Figma 设计一致再做） | P3 |

---

## 三、性能与代码质量

| 序号 | 项 | 说明 | 优先级 |
|------|----|------|--------|
| 3.1 | 网格渲染 | 大网格时用 CSS Grid + 单层 DOM，避免不必要的 key 或列表重渲染 | P1 |
| 3.2 | getRect 缓存 | 画线时 getRect 在单次 path 计算内可复用，避免重复 querySelector | P2 |
| 3.3 | 常量抽离 | 动画时长（LINE_DURATION_MS、TOAST_DURATION_MS）抽到主题或常量文件 | P2 |
| 3.4 | Store 拆分 | 若后续加多游戏，可将 gameStore 按游戏拆文件或加命名空间 | P3 |
| 3.5 | 单元测试 | 为 canConnect、getPath、computeGridSize 等写单测，保证规则正确 | P3 |

---

## 四、可访问性（A11y）

| 序号 | 项 | 说明 | 优先级 |
|------|----|------|--------|
| 4.1 | 焦点与键盘 | 格子支持键盘聚焦与 Enter 选择，便于无障碍与桌面端 | P2 |
| 4.2 | 语义与 ARIA | 网格区域、当前选中格、提示/重排按钮补充 role、aria-label | P2 |
| 4.3 | 色彩对比 | 四种灭火器标签色与背景对比度满足 WCAG AA（当前主题已较友好） | P2 |

## 六、工程与规范

| 序号 | 项 | 说明 | 优先级 |
|------|----|------|--------|

## 建议实施顺序

- **第一阶段（快速提升）**：1.1 消除反馈、1.2 误触防抖、2.1 格子过渡、5.1 规则入口、6.2 主题统一。
- **第二阶段（体验完善）**：1.3 无解检测、2.2–2.4 视觉统一、3.1–3.3 性能与常量、4.1–4.3 可访问性。
- **第三阶段（按需）**：1.4–1.5、2.5、3.4–3.5、5.2–5.4、6.1–6.4。

如需我按某一阶段逐项改代码，可直接说阶段号或具体序号（如「先做 1.1 和 1.2」）。
